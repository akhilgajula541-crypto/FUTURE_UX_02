# Task 2: Mobile App UI for Appointment Booking — Vikram Performance

## 📋 Overview
This project is a mobile app UI for **Vikram Performance**, a fitness training business, allowing clients to browse training programs and book sessions directly from their phone. The goal was to design a fast, low-friction booking flow — from picking a program to confirming a slot — that feels consistent with the brand's website (Task 1).

## 🛠 Tools Used
- **Figma** — UI design and prototyping

## 🔍 Design Process
1. **Research** — Reviewed common fitness/appointment booking app patterns to identify a clear, minimal flow (browse → pick a time → confirm).
2. **User Flow Mapping** — Planned a 4-screen journey: Login → Choose Program → Pick Date & Time → Booking Confirmed.
3. **Wireframing** — Laid out content hierarchy for each screen before applying visual design.
4. **UI Design** — Applied the same brand system as the website (black backgrounds, lime green accents, bold typography) to keep the app and website feeling like one product family.
5. **Prototyping** — Connected the 4 screens into a clickable flow.

## ✅ Key Features
- Onboarding/login screen with phone number login
- Program selection with 3 tiered options, pricing, and feature highlights
- Date & time slot booking interface with clear available/selected/unavailable states
- Booking confirmation screen with a full summary and next-step actions (Add to Calendar, Back to Home)

## 💡 Design Rationale
- **Consistent brand system**: Reused the website's black + lime green palette and bold typography so the app feels like part of the same "Vikram Performance" ecosystem rather than a disconnected product.
- **Minimal login friction**: Phone number login (no lengthy signup form) reduces drop-off before a user even sees the programs.
- **Tiered pricing cards**: Modeled directly after the website's Services page, so returning visitors recognize the same programs and pricing instantly.
- **Clear time slot states**: Available, selected, and unavailable slots use distinct visual states (color, opacity) so users can book confidently without confusion.
- **Confirmation screen completeness**: Showing the full booking summary (service, date, time, price) immediately after booking reduces anxiety and gives users something to reference.
